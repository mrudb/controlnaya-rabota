# Вопрос 02. Базовые типы и преобразование

## Вопросы

Какие базовые типы данных есть? В каких ситуациях какие типы данных используются? Какой тип данных получаем от input? Что такое type conversion?

## Ответ

int,float,str,list,bool,NoneType.
int и float используем когда нужны именно цифры, например в математических операциях. float это дробные, а int это целые числа
str используем когда нам нужно хранить символы
list это тележка-мусорка, которая впитает абсолютно всё, и она безлимитная(не считая занятой оперативки)
bool используем когда нужны 2 конктретных значения: Да(True) или Нет(False)
NoneType это отсутствие значения(не 0, именно отсутствие-пустота)
От input мы изначально получаем str
type conversion это смена одного типа данных на другой, в некоторых пределах разумного. Например нельзя поменять bool на int или float, его можно поменять на str
