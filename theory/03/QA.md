# Вопрос 03. Условия и истинность

## Вопросы

Что такое условие, а что такое условная конструкция? В чём разница между условием и условной конструкцией?

Что вернут и почему:
```python
bool(5869)
bool(0)
bool(12.5)
bool(0.0)
bool(0.0001)
bool("abc")
bool("")
bool(" ")
bool([10, 20, 30])
bool([])
```

## Ответ

Условие это сравнение 2 или более значений.
Условная конструкция содержит условие и тело, которое выполняется если условие = True


bool(5869) = True
bool(0) = False
bool(12.5) = True
bool(0.0) = True
bool(0.0001) = True
bool("abc") = True
bool("") = False
bool(" ") = True
bool([10,20,30]) = True
bool([]) = False
