# Вопрос 04. Операторы и короткое замыкание

## Вопросы

Какие есть операторы сравнения и логические операторы? Какие есть ключевые слова для составления условных конструкций? Что такое короткое замыкание (short-circuit evaluation) и приведите пример.

## Ответ

< > <= >= == != 
not(реверсирует значение условия), or(если одно из 2 или более сравнений = True, тогда всё условие = True), and(все сравнения должны быть True чтобы условие было True, иначе False)
if, else, elif
если используется оператор or и левая часть условия = True, тогда правая часть не выполняется, поэтому с этим оператором надо ставить проверочное сравнение в левую часть, чтобы ненароком не запустить код в теле когда не надо
если используется оператор and и левая часть условия = False, тогда правая часть не выполняется, поэтому с этим оператором надоо ставить проверочное сравнение в левую часть, чтобы не выполнять лишний код если проверка не прошла

num1 = 0
num2 = 1

if num1 != num2 and num1 == num2:
    print(True)     он выведет True, потому что правое условие не проверяется из-за того что левое сравнение дало True
else:
    print(False)



if num1 == num2 or num1 != num2:
    print(True)     он выведет опять же True, потому что левое сравнение дало True
else:
    print(False)
