# Вопрос 05. Независимые проверки и цепочка веток

## Вопросы

Объясните разницу между последовательными if...if...if...else и if...elif...elif...else. В каких ситуациях какой подход применять? Приведите примеры.

## Ответ

Первый вариант это несколько независимых условных конструкций, и если один if даст True, другие будут проверяться тоже
Второй вариант это 1 зависимая условная конструкция, и если один if даст True, остальные проверяться не будут

Если нужно проверить какое-то значение на несколько условий без возможности пересечения этих условий, тогда вариант с независимыми конструкциями

Во всех остальных случаях используем зависимую конструкцию
