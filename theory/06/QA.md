# Вопрос 06. Циклы while и for

## Вопросы

В Python существуют 2 вида циклов - while и for. В чём их разница? Когда какой цикл использовать? Приведите примеры.

## Ответ

while используется когда надо повторить один и тот же код(тело) несколько раз. Нюанс: в цикле while в тело всегда надо ставить строчку кода которая будет изменять значение переменной, иначе мы получим бесконечные итерации
count = 0
while count <= 5:
    print(count)
    count += 1


for это более узконаправленный while, который нужен чтобы пересчитывать или проходить по значениям в коллекции
for count in range(5):
    print(count)        эти 2 варианта дадут одно и то же, просто с for в данном случае писать легче, удобнее, и понятнее если брать в учёт огромные коды

str1 = "abcd"
for char in str1:
    print(char)     он выведет символы отдельно каждый на новой строке


while можно использовать всегда

Но в случаях когда надо пройтись по значениям коллекции или мы знаем точный радиус удобнее использовать for
