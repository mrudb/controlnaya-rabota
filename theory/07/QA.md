# Вопрос 07. break и continue

## Вопросы

Для циклов существуют управляющие операторы break и continue. Когда какой использовать? Приведите примеры.

## Ответ

break отвечает за прерывание цикла(новая итерация не начинается)

continue отвечает за пропуск итерации и начало новой

for num in range(5):
    if num == 3:
        break 
    print(num)
                  когда num будет равно 3, он просто возьмёт и прервёт весь цикл и в терминале выведется только 0,1,2


for num in range(5):
    if num == 3:
        continue 
    print(num)
         когда num будет равно 3, он пропустит только тройку и выведет остальные значения, т.е 0,1,2,4
