# Вопрос 12. Изменение списка и объединение в строку

## Вопросы

Какие есть способы добавлять элементы в list? Какие есть способы изменять элементы в list? Какие есть способы удалять элементы из list и объясните, в каких ситуациях какой вид удаления выбирать? Какие есть способы превратить список элементов в одну строку с разделителем?

## Ответ

append/insert

replace/удалить + insert по одному и тому же индексу

del/pop/remove

del используется когда надо удалить по индексу и не сохранять удалённое
pop используется когда надо удалить по индексу и сохранить удалённое
remove используется когда надо удалить конкретное значение(он не сохраняет удалённое)


split(<разделитель>)
